# Data Provenance

| Class | Meaning | Module |
|---|---|---|
| Reference | Representative published property | Reference Catalogue |
| Measured | Value copied from a real certificate/test | Batches / Mechanical Tests |
| Estimated | Decision-support model output | AI Prediction |

The catalogue includes AA2219-T87, AA2014-T6, AA7075-T6, Ti-6Al-4V Grade 5, Inconel 718, AISI 304L, 18Ni Maraging 300 and AA2195-T8. Each row stores a source title, URL and qualification note.

Values are representative nominal references. Properties change with product form, direction, thickness, temperature and heat treatment; they are not flight design allowables.

The deterministic estimator uses alloy baseline, TIG heat input, HAZ width and repair count. It outputs estimated tensile strength, yield strength, elongation, defect probability, risk and confidence. Results require comparison with real laboratory/NDT evidence.
